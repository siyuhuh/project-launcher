# Runbox visual assets

- `runbox-hero.webp` — lightweight README hero banner.
- `runbox-social-preview.png` — 1280×640 repository social preview source, kept below 1 MB for upload in GitHub repository settings.
- `runbox-overview.jpg` — project dashboard with anonymous demo projects.
- `runbox-health.jpg` — Tasks & Health with API, Web, and Worker ready.
- `runbox-workspaces.jpg` — ordered Full Stack workspace with all tasks ready.

The product screenshots were captured from a temporary, curated Runbox data directory. They do not
contain the maintainer's personal project list. The hero was generated as a text-free abstract
illustration so the real screenshots remain the source of truth for product UI.
